# Security

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/GillMacedo/cgostub/security/advisories/new), not in a public issue.

A wrong result from `cgostub` is a normal bug, so open an issue for it. Report privately only if `cgostub` could be made to run code or write files it shouldn't, beyond the `go list` and `go build` it runs on the packages you name. `cgostub` is a diagnostic aid and doesn't enforce anything.
